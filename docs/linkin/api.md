# 靈境 API

前綴：`/linkin`。

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET/PUT | `/linkin/constitution` | 世界觀憲法 |
| GET/POST/PUT/DELETE | `/linkin/npcs`… | NPC 實體 |
| POST | `/linkin/npcs/{id}/dialogue` | NPC 對白 |
| POST/GET/DELETE | `/linkin/quests…` | 任務實體 |
| GET/POST/DELETE | `/linkin/items…` | 道具實體 |
| GET | `/linkin/events` | 事件 |
| GET | `/linkin/overview` | 總覽 |
| POST/GET | `/linkin/grill…` | 烤問閘門 |

模組目錄見 `GET /modules`（media-vault、local-video-studio）。
